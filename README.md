# Overview
This is the github repo for:

Cummings, S. N., Karboga, G. E., Yang, M., & Jaeger, T. F. (2025). Compensation in audiovisual speech
perception: Discounting the pen in the mouth. Journal of Experimental Psychology: Learning, Memory, and
Cognition. Advance online publication. https://dx.doi.org/10.1037/xlm0001540

It contains all materials, stimuli, experimental lists, data, and analysis code. See also the OSF repo https://osf.io/2asgw/overview with compiled PDFs for the paper and the supplementart information generated from this git repo.
